# Ledgerboard UI fixture

A static two-page app (`index.html`, `settings.html`) styled by `styles/app.css`
with a token block, BEM-style classes, a card/button/form pattern, and no icon
system. `docs/plans/2026-09-06-settings-panel/` holds completed research and an
unstarted design for the mockup workflow evals.

Pages open directly from `file://`; no dev server is required.
